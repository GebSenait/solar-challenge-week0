# ☀️ Solar Analytics Dashboard

Interactive Streamlit dashboard for exploratory solar irradiance analytics and lightweight modeling.

## 🔍 Overview
- Loads prepackaged irradiance datasets for Benin, Sierra Leone, and Togo or your own CSV uploads.
- Cleans and standardises timestamps, handles missing data, and engineers time-based features.
- Visualises key metrics (KPIs, hourly profiles, smoothed time series) and trains a baseline linear regression model to predict DHI.
- Built with `Streamlit`, `Pandas`, `Plotly`, `NumPy`, `SciPy`, and `scikit-learn`.

## 🧭 Repository Structure
```
app/
  __init__.py      # package marker
  main.py          # Streamlit UI
  utils.py         # data loading, cleaning, plotting helpers
data/              # raw CSV inputs for each country
requirements.txt   # Python dependencies
README.md
```

## 💻 Environment Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/<org-or-user>/solar-challenge-week0.git
   cd solar-challenge-week0
   ```

2. **Create and activate a virtual environment**
   ```bash
   python -m venv venv
   ```
   - Windows PowerShell: `.\venv\Scripts\Activate.ps1`
   - macOS/Linux: `source venv/bin/activate`

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 Running the Dashboard

```bash
streamlit run app/main.py
```

Streamlit will display a local URL (e.g. http://localhost:8501). Open it in your browser to interact with the dashboard.

### Available Modes
- **Sample Dataset** – choose Benin, Sierra Leone, or Togo in the sidebar to load curated data shipped in `data/`.
- **Upload CSV** – provide your own dataset with columns:
  - `Timestamp` (supports `%Y-%m-%d %H:%M[:%S]`, common Excel formats, and separate date/time columns)
  - `GHI`, `DHI`, `DNI` (required for full functionality)
  - Additional columns (e.g. `ModA`, `ModB`, `Tamb`) are preserved for display.

### Features Displayed
- **Data Overview** – record counts, time span, and average GHI.
- **Average Daily Solar Profile** – hourly GHI bar chart.
- **GHI Time Series Analysis** – raw vs smoothed (Savitzky–Golay) line plot.
- **DHI Forecasting Model** – baseline linear regression metrics and prediction plots.

## 🧪 Recommended Validation Steps
1. Start the app with `streamlit run app/main.py`.
2. In “Sample Dataset” mode, confirm each country loads without errors and charts render.
3. Switch to “Upload CSV” and test with `data/benin-malanville.csv` (or another dataset with the same schema).
4. Verify KPIs, plots, and model metrics update as expected.

## 📝 Notes
- Cached data is handled via `@st.cache_data`. Use “Clear cache” in the Streamlit menu if you replace data files.
- Autogenerated `__pycache__` folders are ignored and should not be committed.
- VS Code users can select the interpreter at `venv/Scripts/python.exe` for linting and IntelliSense.

Enjoy exploring the solar irradiance data! 🌍⚡
